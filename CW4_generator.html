CW4: генератор вариантов

Генератор исходных данных для задания по простой линейной регрессии. Выберите вариант и скачайте CSV-файл с колонками i, x, y. Подсказка: можно открыть конкретный вариант сразу по ссылке вида ?variant=7.

Данные варианта

Что нужно сделать.
По данным наблюдениям построить простую линейную регрессию, найти доверительные интервалы для коэффициентов регрессии и доверительный интервал для средней функции регрессии.
Исходная таблица
ixiyi
CSV скачивается в формате UTF-8 с разделителем-запятой. Для Excel файл можно открыть напрямую или импортировать как текстовый CSV.
Введите номер варианта от 1 до 15.
